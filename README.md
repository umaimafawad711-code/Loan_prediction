# Applied Machine Learning Mentorship 🚀

Welcome to my Machine Learning journey repository! This repository contains all the weekly assignments, notebooks, and reports completed during my Applied Machine Learning Mentorship.

## 📂 Repository Structure

*   **[Week 1: Data Exploration & Problem Framing](./week1)** - EDA on Amazon RTO dataset.
*   **[Week 2: Data Preparation & Feature Engineering](./week2)** - Cleaning, encoding, scaling, and handling data leakage on the Loan Prediction dataset.
*   **[Week 3: Supervised Models](./week_3)** - Training and comparing KNN, Decision Tree, and Logistic Regression.
*   **[Week 4: Model Comparison & Tuning](./week_4)** - 5-Fold Cross-Validation, GridSearchCV tuning, and overfitting checks using Random Forest and other models.

## 🛠️ Technologies Used
*   Python (Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn)
*   Google Colab
*   Git & GitHub

## 🚀 How to Use
Navigate to any specific week's folder to find its dedicated notebook, dataset link, and a detailed `README.md` explaining the tasks performed. Each notebook is designed to run top-to-bottom without errors.
